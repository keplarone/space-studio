# Space Studio 0.1.2

- New background: a dense three.js star field with many more stars in more colours (blue, white, gold, orange, red, violet), drifting upward with depth, and occasional shooting stars. It pauses when the window is hidden and holds still with Reduce motion on.
- True black interface with neutral greys.
- Generic icons removed. Navigation and buttons are plain text.
- Cleaner layout: no decorative gradients, glows, badges or card grids.

Installers are still not code-signed. Windows SmartScreen and macOS Gatekeeper will warn; on macOS, right-click the app and choose Open. Use SHA256SUMS to check your download.
