# Space Studio 0.3.2

- Fixed: pressing Next or Skip tour (and other clicks) could freeze the window. The top bar kept re-measuring its tab highlight in an endless loop, which locked up the app as soon as it ran inside a click. It now measures only when the tab or window size changes, which also cuts idle CPU use.

Installers are still not code-signed. Windows SmartScreen and macOS Gatekeeper will warn; on macOS, right-click the app and choose Open. Use SHA256SUMS to check your download.
